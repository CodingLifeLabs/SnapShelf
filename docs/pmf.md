# SnapShelf PMF 현황

> [Product–Market Fit] 단계·지표·기능 우선순위 기준.
> PMF 필터를 통과하지 못한 기능은 구현하지 않는다(CLAUDE.md 절대 규칙).

## 단계

- **현재**: v0.1.2 공개 (13 스프린트 완주, 사용 통계+안정화) — 실사용 피드백 수집 단계
- **목표**: 데스크톱 유틸리티로서 "매일 쓰이는" 루틴 형성 (core loop: 캡처 → Shelf → 다시 찾기)

## 핵심 루프(Core Loop)

```
캡처  →  Shelf(즉시 접근)  →  자동 정리(Smart Folder)  →  나중에 검색/재사용
```
이 루프가 매일 5회 이상 반복되면 유지. Shelf 단독(Sukurini)은 2단계에서 끝나고,
"다시 찾기(정리·검색)" 가 두 번째 물림(second-bite)을 만든다.

## 우선순위 기준

1. **P0**: 핵심 루프를 깨뜨리면 제품이 성립하지 않음 (Shelf, 자동정리, 검색)
2. **P1**: 차별화·두 번째 물림 (AI 이름변경/요약, 타임라인, Dev Mode)
3. **P2**: 가치 확장 (클립보드 히스토리, 녹화 정리, 중복탐지)

## 검증 지표 (v0.1.0 공개 후 수집)

- 다운로드/설치: GitHub Release 다운로드 수, 랜딩→CTA 전환
- DAU/MAU 루틴: 하루 캡처 후 Shelf 재접근 비율
- "다시 찾기" 성공률: 검색→클릭/드래그 전환
- 정리 적중률: Smart Folder 자동 분류 정확도
- 리포지토리: 별/이슈 — 기능 요청 vs 버그 비율로 다음 우선순위 결정
